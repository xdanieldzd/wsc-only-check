# WonderSwan Example Code: "Only for WonderSwan Color" Screen

Some WonderSwan example code, which will display an error message on an original, monochrome WonderSwan.

The most important bits are in the files named `wscerr.*`, these *should* be easily reusable unchanged in other projects. The Color part is just a basic scrolling demo.

Written in C using the [Wonderful Toolchain](https://wonderful.asie.pl/).
